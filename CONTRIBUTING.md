# Contributing

Thank you for helping improve RAM Watch! Bug reports, ideas and pull requests are welcome.

## Ground rules
- Keep it ultralight: no new libraries or SDKs without discussion. The APK should stay well under 100 KB.
- No ads, analytics or tracking code of any kind.
- One feature or fix per pull request, with a short description and a screenshot for UI changes.
